OAUTHCONNECT · VUE PÉDAGOGIQUE · 7 NOVEMBRE 2026

Un service configurable, deux profils de connexion

Cible en construction — pas encore raccordée à IAM
API backend cible POST /oauth-connect/{instance}/v2/authorize POST /oauth-connect/{instance}/v2/complete

HMAC propre à chaque instance · signature du PATH complet reçu · préfixe /oauth-connect monté une seule fois · jamais d’ID token ni de claims bruts vers IAM.

ACQUIS · lot précédent

Config, mapping OAuth, HTTP/secrets et contrat v2. 189 tests du lot précédent ; ce n’est pas une preuve OIDC.

EN COURS · ce lot

OIDC + cache JWKS, registry et service. D’abord le socle T0, puis les preuves RED → GREEN ; aucun GREEN anticipé.

HORS LOT · pas encore raccordé

Adaptation IAM et nonce durable, E2E fournisseurs externes, bascule et déploiement. Aucune livraison live annoncée.

Ce qui change : deux services vendor → un service configurable cible ; les services legacy restent pendant la transition.

Ce qui reste : identité externe = instance + sub/id ; UUID IAM préservés, aucune migration des comptes. L’équivalence de l’ancien ID GitLab reste une gate de bascule.

Pas de mémoire métier dans Connect : aucun cache de corrélation OAuth ; seul le cache technique JWKS est prévu par instance.
