# IAM CI compile-once A/B qualification

This push-only experiment on `ci-iam-ab` uses the same application source, RustyCog
pin and `ubuntu-24.04` runner class in both arms. It is not a delivery workflow.
Telegraph, Pages and Sonar are outside the experiment; their normal gates are
unchanged.

- **A:** current native IAM server/migration build and the original per-partition
  `cargo llvm-cov` commands, with their existing fixtures and coverage receipts.
- **B:** the PR #5 producer freezes the instrumented IAM server/migration, builds
  the five test bundles, and succeeds before k6 or replay is eligible. Replay
  uses the same test partitions and fixtures without recompiling.
- Both k6 jobs get the same native OAuthConnect and Ext Authz bundles. All
  executable bundles come from successful producers in the same run and attempt;
  the two IAM bundles and their E2E evidence cannot cross arms or become
  canonical CI or saved-image artifacts.

## Comparison protocol

Compilers start with empty job-local caches. The Cargo download cache can be
restored read-only, with no benchmark-arm writes. Check actual restore outcomes
and runner image versions in job logs. A cold compiler comparison is intentional:
this does not estimate an already-warm shared compiler cache. Jobs in the same
run can still see different runner queue times, image revisions and network
latency. One pair does not establish typical performance.

Use the same run's start as the origin. Define k6 eligibility as the last required
producer's successful finish; separately measure E2E job start and the first
actual k6 case. Coverage availability is the last of the five coverage job
completions; joint availability is the later of coverage and E2E completion.
Report sum of occupied runner seconds, which includes setup, downloads,
fixtures and cleanup, not just CPU time. Sum exact-run executable ZIP sizes
separately from the small evidence archives; companions are common to both arms.

Only compare two qualified arms. Verify API SHA-256 on downloaded evidence;
require five distinct matching IAM partitions with zero test/report exits,
nonempty digest-matched LCOV and matching disjoint target sets. Verify B's
direct-libtest receipt per partition, and both k6 reports' source, SDK,
producers, instrumentation, five cases, SAN restoration and zero owned
resources running. Compare the timing only after these checks.
