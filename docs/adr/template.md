# ADR-NNNN : Titre = la décision en une phrase

- Statut : Proposed
- Réalité : Unimplemented | Partial | Implemented
- Date : YYYY-MM-DD
- Décideurs : (à remplir à l’acceptation)
- Jalon concerné : P0 | P1 | P2 | P3 | P4 | P5 | P6
- SuperSède : aucune
- SuperSédée par : —

`Accepted` ratifie une cible. Le champ `Réalité` indique séparément ce que le code du dépôt réalise et doit citer une preuve dans les références.

## Contexte

Quel problème, quelle contrainte du dépôt actuel, quelle tentation à éviter. Citer le code et la baseline wiki antérieure à l’ADR, pas une page dérivée qui la cite en retour.

## Décision

Le choix, au présent. Bornes V1. Ce qui est explicitement hors décision.

## Conséquences

Positives, négatives, travail imposé (migrations, tests, APIs). Ce que le code ne doit plus faire.
