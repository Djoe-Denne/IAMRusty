Contract: `docs/contracts/apparatus-knative-runtime.md`, §12 B2/B5,
§14 B and §15 B, accepted 2026-10-20. This folder is deliberately absent
from the parent kustomization. Do not apply it: the lock is unresolved.

not API validation, compatibility evidence or a deployment/publication gate.

## Static criteria and remaining gates

- Ratified KPA/min/initial zero, positive maximum 2, global maximum limit 2,
  concurrency 1, idle windows and deadlines: `profile.yaml` and
  `serving-config.yaml`. ConfigMap templates are specifications for C/D,
  not enforcement. Exact accepted keys/schema must be verified at the pin.
- Total resources explicitly split across user, queue-proxy, transport and
  sandbox overhead in `profile.yaml`. RuntimeClass overhead is already part
  of that budget, not extra. Limit overhead is accounting headroom, not a
  separately enforceable RuntimeClass field. Temporary volume size and actual
  container limits must be generated by C using verified platform settings.
- No unlimited/public default: positive scaling maximum; no public gateway;
  empty ingress/egress and mesh allow rules; zero-capacity namespace quota.
  This is intentionally nonfunctional quarantine, NOT a working bounded runtime.
  Quota is namespace-wide (including legacy workloads); never apply alongside
  legacy P4. Approved capacity must replace zero before deployment and account
  for coexisting Revisions, all bindings and shared system load.
- TLS/SA/ports/probes graph: `profile.yaml` trust-graph. No invented port or
  path exception. NetworkPolicy cannot enforce paths. The exact standard
  net-istio gateway, probe/metrics paths/ports, immediate SPIFFE peers,
  mesh bootstrap credentials, node/SNAT behavior and plugin-to-Lazaret-only
  allow rules remain BLOCKED_TBD_SPIKE. No broad DNS/API/node exception.
- Strict mTLS and empty ALLOW in `transport-policy.yaml`; gateway contract
  in `ingress.yaml`. No headers grant authority. No DestinationRule or
  gateway TLS stanza guessed before upstream topology/pin resolution.
- gVisor RuntimeClass handler is an invalid-to-operate placeholder; node
  installation, shim/runsc pin and sidecar compatibility remain blocked.
  System/plugin pool contract in `placement.yaml`; node/stack placement
  cannot be claimed enforced by a ConfigMap. Multiple bindings per node allowed.
- Ownership: no binding Service or Serving children rendered. Dedicated
  adapter Role covers parent Serving Services only; plugin SA has no RBAC
  and no automatic token mount. Legacy controller Pod RBAC is not reused.
  C must fence the legacy writer and own binding fields exclusively at cutover;
  no Flux/adaptor double writer, chart publisher, second queue, HPA or KEDA.
- Four aggregate waiting requests and 256 KiB payload are NOT enforced here.
  Spike must identify standard controls across replicas. Per-proxy breaker
  is insufficient; unsupported bound requires STOP and contract amendment,
  not a home-grown limiter. Native retries/absolute deadlines also need proof.
