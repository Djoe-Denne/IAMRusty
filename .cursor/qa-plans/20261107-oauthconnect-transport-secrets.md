### A-1 — authorize, allowlist et contexte v2 [GAP ; effort petit]

- Négatifs : redirect proche (autre host/port/chemin/query/suffixe), PKCE désapparié/méthode non S256/capacité absente, champs requis v2 invalides → `Err`, compteur vendor=0. OAuth garde nonce dans la frontière v2 mais ne le met dans **aucun** paramètre vendor ; verifier n'apparaît pas à authorize. Ne pas promettre ici la consommation writer IAM, hors lot.
- Oracle : paramètres URL décodés exacts et reçus réseau vides. RED nominal attendu sur socle : refus « non implémenté » à la place de l'URL autorisée ; ne pas fabriquer un RED si une caractérisation est déjà verte.

### A-2 — token POST, auth explicite et DTO tokens [GAP ; effort moyen]

- Nominal : fixtures Basic et Post distinctes ; POST form contient grant_type=authorization_code, code, redirect exact et verifier attendu ; Accept JSON, pas de token/code/verifier dans la query. Basic : header décodé = client_id/client_secret attendus, pas de client_secret dans form ; Post : credentials dans form, pas de Basic Authorization. Code/secret/verifier synthétiques avec caractères nécessitant encodage form.
- Réponse : access_token non vide, token_type Bearer compatible (témoins Bearer/bearer), refresh/expiry optionnels ; expires_in entier u64 quand présent. Négatifs : access/token_type absent/vide/mal typé ou schéma non Bearer ; expiry négatif/fraction/string/horsu64 refusé. Pas de règle métier inventée interdisant0 ; ni refresh ni email synthétiques.
- Oracle : reçu unique filtré POST+path+phase, form décodée et headers exacts, valeurs tokens/profil attendues. 401/403 ou méthode refusée→un seul POST, **aucun essai Basic↔Post**, aucun GET profile après échec token. Même code non rejoué par le client après timeout/erreur ; pas d'appel v1.
- RED attendu : complétion valide refusée par socle, mauvaise méthode/absence du verifier ou réponse DTO incomplète détectées par assertions. Aucun mock de `complete_authorization` lui-même.

### A-3 — GET configurés, journal par opération et projection [GAP ; effort moyen]
