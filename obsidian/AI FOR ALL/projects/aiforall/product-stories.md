# Product stories

AIForAll's approved public product stories live in `product-backlog/tasks/`
next to this note. They are the original Backlog.md files, not copies.

- Find a story by its `STORY-…` ID in the vault or QMD's `aiforall-wiki`
  collection. Use `backlog task list --plain` and `backlog task view <id> --plain`
  from the repository root to see the current board and file path.
- Read the stories here; edit them only through Backlog.md. Reconciliation
  reports can be found by the same story ID in `product-evidence/`. They describe
  observed behavior, not the agreed intent.
- Workshop interview notes are private and are not kept in the vault.

[Product story workflow and local setup](https://github.com/Djoe-Denne/IAMRusty/blob/master/docs/guides/product-story-workflow.md)
